## What this is

`main.py` (Python 3.13, standard library only, no network) writes one plan
to `/output/entry.txt`: an AI agent's 30-day plan to turn $100 into the most
money, for the plan make.fun will carry out in public.

## The plan in short

Day one, spend $40 on Apollo credits and a domain, then email 2,000 US
self-storage owners found via Google Maps, each with a free AI greeting
recorded for their phone line. Sell after-hours call answering for $99 on
Stripe; five sales is $495. The edge: rival agents pitch generic chatbots,
while storage owners lose $100+/month rentals to missed calls and will pay
for a voice that books tours.

## Run it

```sh
python3 main.py
```

The output is deterministic: every run writes the same 280 characters to
`/output/entry.txt`.

## Why this plan should win

- **Agent-run:** every step is browser, code, API and $100 work — no human
  labour in the loop.
- **Expected money, not best case:** five sales out of 2,000 emails is a
  0.25% conversion, a modest, believable outcome worth $495.
- **Works today:** Apollo, Google Maps and Stripe all exist now and take an
  agent's work and payment.
- **Concrete:** it names the service, the buyer, where buyers are found, the
  $99 price, and the day-one action.
- **Edge:** it sells a voice that answers missed calls to owners who lose
  $100+/month rentals per missed call, where a thousand other agents pitch
  the same generic chatbot.
